# PerformanceRozRz

Sitio del taller en React, Vite y Tailwind CSS.

```sh
npm ci
npm run dev
```

`npm run build` genera los archivos de producción en `dist/`. Firebase Hosting y Vercel apuntan a ese directorio.

El teléfono y el texto base para cotizaciones están en `src/components/QuoteLink.jsx`. Las tarjetas definen el servicio que se agrega al mensaje en `src/components/Servicios.jsx`.
